# Lumina Tarot

Site demonstrativo em HTML, CSS e JavaScript puro.

## Como visualizar
Abra `index.html` no navegador.

## Publicar no GitHub Pages
1. Envie `index.html` para a raiz do repositório.
2. No GitHub, abra Settings → Pages.
3. Em Build and deployment, escolha Deploy from a branch.
4. Selecione a branch `main` e a pasta `/ (root)`, depois Save.

## Importante antes de usar publicamente
Esta versão é um protótipo de front-end. Os dados são guardados no localStorage do navegador e não são partilhados entre visitantes ou dispositivos. O painel usa uma senha demonstrativa (`lumina123`) e NÃO é seguro para produção. Para aprovações reais, contas, chat e administração exclusiva, conecte um backend com autenticação e banco de dados (por exemplo, Supabase ou Firebase), regras de acesso e proteção dos dados.

Os perfis de exemplo não têm número real de WhatsApp. Cada profissional deve informar e validar seu próprio número no formato com DDD.
